# About

**ML for Physicists** is Ethan's collection of notes, exercises, and worked notebooks for
learning machine learning from a physics starting point.

## Who this is for

Physics students and researchers who want a practical, code-first path into machine learning:
comfortable with Python and undergraduate physics, new to ML.

## How the site is built

- Content is written in Markdown and Jupyter notebooks, built into a static site with
  [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) and rendered via
  [`mkdocs-jupyter`](https://github.com/danielfrg/mkdocs-jupyter).
- Hosted for free on [GitHub Pages](https://pages.github.com/), rebuilt automatically on every
  push to `main` via GitHub Actions (see `.github/workflows/ci.yml`).
- Source lives in a public GitHub repository &mdash; contributions, corrections, and issues are
  welcome via the :material-pencil: *Edit this page* link at the top of each page.
