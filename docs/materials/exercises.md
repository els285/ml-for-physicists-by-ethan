A generic exercise sequence, mirroring the topic order in [Course Materials](index.md):

- [ ] **Tensors** &mdash; basic tensor creation, indexing, broadcasting, and autodiff.
- [ ] **Regression with scikit-learn** &mdash; a classical baseline before touching PyTorch.
- [ ] **Regression with PyTorch** &mdash; the same problem, rebuilt as a small neural network.
- [ ] **Classification** &mdash; a binary classifier on a simple dataset.
- [ ] **DNN for HEP** &mdash; the signal-vs-background classifier developed in the
      [Notebooks](../notebooks/index.md) section, plus the "mastering model building" bonus tasks
      (optimizers, dropout, early stopping, feature importance).

Each exercise would typically ship as two notebooks: a `*_exercise.ipynb` with blanks to fill in,
and a `*_solutions.ipynb` with a worked answer &mdash; the same pattern used by the HEP notebooks.
