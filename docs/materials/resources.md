# Resources

A generic starting reading list &mdash; swap in your own recommendations.

## Textbooks & notes

- *Deep Learning* &mdash; Goodfellow, Bengio, Courville (free online).
- *Dive into Deep Learning* &mdash; interactive book with runnable code (d2l.ai).
- Course lecture notes from your own institution's ML/stats courses.

## Physics-specific ML

- *Machine Learning and the Physical Sciences* workshop proceedings (NeurIPS).
- HEP Software Foundation's "Machine Learning for Particle Physics" community resources.
- Living review articles on deep learning in particle/astro/condensed-matter physics.

## Tools used in this course

- [PyTorch](https://pytorch.org/) &mdash; the deep learning framework used throughout.
- [PyTorch Lightning](https://lightning.ai/docs/pytorch/stable/) &mdash; structure for scaling up
  training loops, used in the [DNN for HEP: PyTorch Lightning](../notebooks/DNN4HEP_lightning.ipynb)
  notebook.
- [scikit-learn](https://scikit-learn.org/) &mdash; classical ML baselines, preprocessing, and
  evaluation metrics.
- [Weights & Biases](https://wandb.ai/) / [MLflow](https://mlflow.org/) &mdash; optional
  experiment tracking, useful once you move past single training runs.

## External courses

- fast.ai &mdash; *Practical Deep Learning for Coders*.
- Stanford CS229 / CS230 lecture notes.
- Any institution-specific "ML for physicists" course notes you want to cross-link here.
